# cyaichi.com

Public source for [cyaichi.com](https://cyaichi.com), the distribution point for Cyaichi research.

Cyaichi is independent research and method development in **AI-driven cybersecurity**: threat intelligence, modeling, detection, and response.

Published methods and prototypes live in the public research repo: [github.com/cyaichi/cyaichi](https://github.com/cyaichi/cyaichi).

## Status

The site is not built yet. This repository exists so writing, talks, and the domain have a home separate from research output.

## Not this repo

This is not a SIEM product, an MDR shop, or a CVE news feed. Public writing here should teach a method, an analysis, or a synthesis from Cyaichi work.
